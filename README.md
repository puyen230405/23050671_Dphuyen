# AIDEOM - Dashboard mô hình ra quyết định

## Cách chạy

Cách 1: mở trực tiếp file `index.html`.

Cách 2: chạy local server:

```bash
cd AIDEOM_FINAL_UPDATED
python -m http.server 8000
```

Mở trình duyệt tại: http://localhost:8000

## Những điểm đã chỉnh trong bản này

- Đổi toàn bộ font sang Times New Roman.
- Bỏ câu chữ gây cảm giác bản nháp như "phiên bản".
- Bố cục biểu đồ được tăng chiều cao, xoay nhãn và chống cắt chữ.
- Tăng độ sâu phần phân tích trong từng bài.
- Thay tab "Phân tích AI" bằng "Phân tích tác nhân".
- Cải thiện tác nhân phân tích theo 3 hướng: học thuật, chính sách, phản biện.
